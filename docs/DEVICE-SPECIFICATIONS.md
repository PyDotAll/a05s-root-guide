# Device specifications and privacy

This guide targets the Samsung Galaxy A05s (`SM-A057F`). Hardware, firmware, carrier
configuration, and bootloader status vary by region and software release. Confirm those details
on the device and with the firmware source before flashing.

## Check details locally

Use **Settings → About phone → Software information** to check the model, build, baseband,
security patch, and service provider software version. Match the firmware to the device's
current model and CSC. Do not rely on another person's screenshots or configuration.

## Keep identifiers private

Do not commit or post serial numbers, IMEIs, phone numbers, account identifiers, network
addresses, exact storage usage, or screenshots containing personal data. If a trusted firmware
tool requires a device identifier, enter it directly into that tool and do not save it in this
repository, issue reports, or shared logs.

This document intentionally contains no live device measurements or identifiers.
